# 🎓 Suolingo Web — AI-Powered Language Learning Platform

Suolingo Web is a modern language learning application built with AI speech capabilities.  
It allows learners to practice English pronunciation using real-time feedback and interact with an AI avatar.

---

## 🚀 Features

- 🎤 **Speech-to-Text (STT)**  
  Detects pronunciation and highlights incorrect words.

- 🔊 **Text-to-Speech (TTS)**  
  Users can listen to the correct version of each sentence.

- 🤖 **AI Avatar Integration**  
  The avatar speaks, reacts, and guides the user while practicing.

- 🌐 Web-based front-end built using TypeScript + React.

---

## 🛠️ Tech Stack

| Category | Technology |
|---------|------------|
